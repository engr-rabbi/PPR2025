# PPR 2025 — Bangladesh Public Procurement Interactive Training Guide

> **Complete PPR 2025 Interactive Learning + Practical Reference + e-GP Training + Tender Evaluation Guide**

An interactive, practical and visually enhanced training/reference website for **Public Procurement Rules (PPR) 2025 in Bangladesh**.

🌐 **Live Website:** https://engr-rabbi.github.io/PPR2025/

---

## 📚 About This Project

This project presents PPR 2025 concepts in a learner-friendly web format, combining:

- PPR 2025 rules and explanations
- Procurement methods and practical examples
- Tender preparation and evaluation guidance
- e-GP practical workflow
- Tender Evaluation Committee (TEC) training
- Checklists and quick-reference material
- FAQs, quizzes and glossary resources
- Real-life procurement scenarios
- Interactive diagrams and workflow visualizations
- Mobile-responsive learning experience

The objective is to make procurement knowledge easier to **understand, apply and revise** for beginners, practitioners, evaluators and advanced users.

> ⚠️ **Legal Notice:** This website is an educational/reference resource. For legal, contractual or official procurement decisions, users should verify the applicable provisions against the official BPPA PPR 2025 Gazette and other authoritative government sources.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/engr-rabbi/PPR2025.git
```

Open the project directory:

```bash
cd PPR2025
```

For a simple static version, open `index.html` in a browser.

For the best development experience, use a local HTTP server, for example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

---

## ⚖️ Legal & Accuracy Disclaimer

PPR 2025 is a legal/procurement reference area. Therefore:

- Official provisions should remain distinguishable from explanatory content.
- Illustrative examples should be identified as such.
- Visual diagrams must not imply a legal requirement that is not actually established.
- Users should verify important legal/procurement decisions against the official BPPA PPR 2025 Gazette and applicable official guidance.

**This project should not be treated as a substitute for the official Gazette, government instructions, legal advice or formal procurement authority decisions.**
